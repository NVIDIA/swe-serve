# Security

NVIDIA is dedicated to the security and trust of our software products and services, including
all source code repositories managed through our organization.

If you need to report a security issue, please use the appropriate contact points outlined
below. Please do not report security vulnerabilities through GitHub issues.

## Reporting a potential security vulnerability

To report a potential security vulnerability in any NVIDIA product:

- Web: the Security Vulnerability Submission Form at
  https://www.nvidia.com/object/submit-security-vulnerability.html
- E-mail: psirt@nvidia.com, with the PGP key published at
  https://www.nvidia.com/en-us/security/pgp-key/

OEM partners should contact their NVIDIA Customer Program Manager. NVIDIA's product security
information is at https://www.nvidia.com/en-us/security/.
